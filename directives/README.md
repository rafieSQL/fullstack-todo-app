# Layer 1: Directives (SOPs)

This directory contains Standard Operating Procedures (SOPs) and task specifications for the AI Agent and team.

## Structure of a Directive

Each directive should define:
1. **Goal**: Clear objective of the task.
2. **Inputs & Prerequisites**: Dependencies, files, and environment requirements.
3. **Execution Steps**: Step-by-step deterministic instructions.
4. **Expected Output**: Acceptance criteria and verification checklist.
5. **Edge Cases & Error Handling**: What to do when common failure modes occur.
