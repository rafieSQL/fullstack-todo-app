# Landing Page Architecture & Craft Aesthetics Skill

## 1. Craft Aesthetic & Anti-AI Slop Guardrails
- **Strict Anti-AI Slop Rules**:
  - DILARANG menggunakan ilustrasi robot, karakter 3D melayang cheesy, atau gradien ungu/pink blur klise.
  - DILARANG menggunakan background mesh berlebihan atau stock mockup smartphone/laptop yang tidak realistis.
  - Visual wajib mengadopsi standar produk produktivitas engineering mutakhir (Linear, Raycast, Cron style):
    - **Background Canvas**: Monokrom gelap pekat murni (`#050505` / `#0a0a0a`).
    - **Grid & Borders**: Garis grid arsitektural halus presisi (`rgba(255, 255, 255, 0.08)` / `border-white/[0.08]`).
    - **Typography**: Sans-serif tajam (*Inter*, *Geist*, *-apple-system*) dengan angka monospaced (*JetBrains Mono*, *monospace*) untuk counter dan metrik teknis.
    - **Badges**: Pill badge teknis dengan border halus dan font monospace ringkas (`⌘ Minimalist Voice-First Productivity Workspace`).
- **Mikro-Animasi & Interaktivitas CSS**:
  - Spotlight card hover: Border dan highlight permukaan mengikuti atau merespons kursor hover.
  - Subtle border-beam glow: Cahaya garis tepi lembut pada elemen hero dan paket utama.
  - Smooth morphing tabs & toggles: Transisi switch bulanan/tahunan yang instan dan mulus.

## 2. Pricing Strategy & Psychology Engine
- **Billing Switch & Incentive**:
  - Toggle pilihan durasi pembayaran: **Bulanan** vs **Tahunan**.
  - Badge insentif tahunan: *"Hemat 25%"* (menyederhanakan keputusan komitmen jangka panjang).
- **Decoy Effect & Value Anchoring**:
  - Paket **Pro ($8/bln)** bertindak sebagai sweet spot paket terpopuler.
  - Paket **Pro+ ($12/bln)** bertindak sebagai value anchor (selisih tipis $4/bln namun membuka seluruh kapabilitas eksklusif tanpa batas).
  - Paket Pro diberi visual anchoring dengan badge *"Paling Populer"*, border aksen emerald kontras (`#10b981`), dan tombol CTA utama yang menonjol.
- **Feature Gating & Tier Breakdown**:
  - **Free ($0)**: Core task registry, standard 25m Pomodoro timer, 1 workspace lokal, manual scheduling.
  - **Pro ($8/bln)**: Unlimited Voice Partner (Whisper + Llama 3), live tab sync multi-device, ambient soundscapes, Chronos smart timeline, unlimited workspaces.
  - **Pro+ ($12/bln)**: Prioritas cloud API bandwidth, Reverse Trial 14 hari, advanced velocity auto-morphing, custom soundscapes, export & calendar webhook integrations.
- **Reverse Trial Conversion Banner**:
  - Callout banner persuasif: *"Dapatkan akses 14 hari Pro+ gratis saat pertama mendaftar tanpa kartu kredit"*.

## 3. Component Hierarchy & User Flow
- **Sticky Glass Navbar**: Logo brand, anchor navigation (*Features*, *Workflow*, *Pricing*), dan tombol `Masuk / Login` serta `Buka Workspace ->`.
- **Hero Section**: H1 persuasif (*"Struktur Harian Anda. Dirancang Tanpa Distraksi."*), subtext tajam, dual CTA, dan Interactive Browser UI Mockup.
- **Bento Grid Showcase**: 3 showcase modular (*Voice Command Natural Engine*, *Deep Work Pomodoro Hub*, *Timebox Day/Week Calendar*).
- **Interactive Pricing Matrix**: Switch billing, 3 tier cards, dan feature comparison table dengan checklist jelas.
- **Minimalist Footer**: Metadata, privacy notice, copyright, dan live operational status indicator.
